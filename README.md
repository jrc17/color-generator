# Color Generator

The Color Generator is a frontend app that generates color palettes based on a selected base color and theme.

## How It Works

- The user selects a base color and a color scheme theme
- The app sends a request to an external color API
- A color palette is returned and rendered dynamically in the UI

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- REST API
- JSON
